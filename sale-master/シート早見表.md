## まず結論：普段さわるのは3枚だけ

| | シート | いつ直す |
| --- | --- | --- |
| **毎月** | `sales` | 今月のセールを1行足す／終わった行は放置でOK |
| **たまに** | `links` | 常時キャンペーンや5と0の日のリンクが変わったとき |
| **たまに** | `schedule`（`common` の行だけ） | 5と0の日の投稿コピー案を入れ替えたいとき |

残り9枚は **スーパーSALE（3・6・9・12月）のときだけ** 使います。
普段の月は白紙のままで問題ありません。

## 全12シート一覧

`頻度` の見かた … ⭐️毎月／🔸ときどき／🔺スーパーSALEのみ／⚙️自動

| シート | 頻度 | 出る場所 | 中身 |
| --- | :-: | --- | --- |
| **sales** | ⭐️ | 全ページの土台 | 1行＝1セール。ここに無いセールはどこにも出ない |
| **links** | 🔸 | セール情報ページ | リンク集。`区分`で3種類に分かれる（下記） |
| **schedule** | 🔸🔺 | 5と0の日セクション／投稿スケジュール | `common`の行＝5と0の日コピー案／セールIDの行＝日別スケジュール |
| **ranking** | ⚙️ | 人気ホテル一覧 | 予約実績から自動集計。**手で触らない** |
| phases | 🔺 | セール詳細「開催スケジュール」 | 告知→先行→本番→最終日のタイムライン |
| phase_subs | 🔺 | 同上の入れ子 | 「5と0の日 72時間×4回」の内訳 |
| points | 🔺 | セール詳細「訴求ポイント」 | POINT 01〜03 の3枚カード |
| campaigns | 🔺 | セール詳細「開催キャンペーン」 | ポイントバック等の説明カード |
| **tickets** | 🔺 | セール詳細「観光体験チケット」 | 遊園地・水族館などの前売り券 |
| **services** | 🔺 | セール詳細「その他サービス」 | 楽パック／レンタカー／バス／海外の割引率 |
| **banners** | 🔺 | セール詳細「バナー素材」 | Notionのバナー置き場へのリンク |
| schedule_phases | 🔺 | 投稿スケジュールの見出し | 「告知・先行SALE期」などの区切り |

> **ご質問の tickets・services・banners は、まさにスーパーSALE専用です。**
> 楽天から事前に共有される資料に載っている内容を、そのまま転記する枠として作りました。
> 普段の月は空でよく、実際いまも2026年6月の行しか入っていません。

## 連動の全体像

```
┌─ sales ─────────────────────────────────────────────┐
│  ここが起点。種別で扱いが変わる                        │
│                                                      │
│  種別 = common    → 常設（いつでも出る）               │
│  種別 = sale      → 簡易セール（カード1枚）            │
│  種別 = supersale → 詳細セール（下の9枚が効く）        │
└──────────────────────────────────────────────────────┘
       │
       ├─ common の行 ────────────────────────────────
       │    ├─ links（区分=always）  → 常時開催中のキャンペーン
       │    ├─ links（区分=fifty）   → 5と0の日のリンク
       │    ├─ schedule             → 5と0の日の投稿コピー案
       │    └─ 5と0の日開催時間      → 「今月は48時間開催」
       │
       ├─ 種別=sale の行 ────────────────────────────
       │    └─ その行だけで完結（カード1枚）
       │
       └─ 種別=supersale の行 ───────────────────────
            ├─ phases / phase_subs   → 開催スケジュール
            ├─ links（区分=plan）     → 施策別リンク一覧
            ├─ points                → 訴求ポイント
            ├─ campaigns             → 開催キャンペーン
            ├─ tickets               → 観光体験チケット
            ├─ services              → その他サービス
            ├─ banners               → バナー素材
            └─ schedule_phases / schedule → 投稿スケジュールタブ

ranking ← 楽天トラベルホテル購入詳細【元データ】から自動集計（sales とは独立）
```

**すべてのシートは `sale_id` 列でつながっています。** `sales` に書いた `sale_id` を、
他のシートの `sale_id` 列に同じ文字列で入れることで紐づきます。

## ページのどこに出るか

### 🌐 セール情報（トップ）

| 上から | シート | 表示条件 |
| --- | --- | --- |
| ヒーロー（大きい見出し） | `sales` の `hero_*` | スーパーSALE中はそちら、平時は `common` |
| ① 今月開催中のセール | `sales` | `開始日時`〜`終了日時` の期間内 |
| ② 常時開催中のキャンペーン | `links`（`always`） | いつでも |
| ③ 毎月5と0のつく日 | `links`（`fifty`）＋`schedule`（`common`） | いつでも |
| ④ スーパーSALE詳細 | phases／points／tickets ほか | supersale の期間内のみ |

### 🌐 ◯月投稿スケジュール

`schedule_phases` と `schedule`（そのセールのID）。
**3・6・9・12月にしかタブが出ません。** 出し始める日は `sales` の `スケジュール公開日` で指定。

### 🌐 人気ホテル一覧

`ranking` のみ。文言は `sales` の `ランキング見出し`／`ランキング説明`（`common` の行）。

## 毎月やること（普通の月）

`sales` に1行足すだけ。**7列** を埋めます。

| 列 | 例 |
| --- | --- |
| `sale_id` | `2026-09-aki` （一意ならなんでもよい） |
| `公開` | `TRUE` |
| `種別` | `sale` |
| `セール名` | 楽天トラベル 秋旅セール |
| `開始日時` | `2026-09-01 10:00` |
| `終了日時` | `2026-09-15 23:59` |
| `ひとこと説明` | 対象宿が最大20%OFF。秋の連休の予約におすすめです。 |
| `セールURL` | https://travel.rakuten.co.jp/… |

`sale_id = example` の行（公開=FALSE）をコピーして書き換えるのが早いです。

> **ひとこと説明はカードにそのまま出ます。**記入例の文が残ったままにならないよう注意。

書けたら **メニュー「🚀 攻略サイト」→「② サイトに公開する」**。

## スーパーSALEの月にやること（3・6・9・12月）

1. `sales` に1行足す。`種別` を **`supersale`** に
   - `期別ラベル` に `2026年9月` → ヘッダーのバッジとタブ名になる
   - `スケジュール公開日` に告知開始日 → その日から投稿スケジュールタブが出る
2. 楽天から来た資料を見ながら、同じ `sale_id` で各シートに行を足す

| シート | 何を書くか |
| --- | --- |
| `phases` | 告知開始／先行SALE／本SALE開幕／最終日 の4〜5行 |
| `phase_subs` | 5と0の日の開催日程（`phases` の何行目にぶら下げるかを `親表示順` で指定） |
| `links`（`plan`） | 施策別リンク。`グループ` で告知期間／先行SALE／本番SALE に分ける |
| `points` | 今回の目玉3つ |
| `campaigns` | ポイントバック等 |
| `tickets` | 観光体験チケット（無ければ空でよい） |
| `services` | 楽パック・レンタカー等の割引率（無ければ空でよい） |
| `banners` | Notionのバナー置き場のURL |
| `schedule_phases` → `schedule` | 日別の投稿コピー案 |

3. 前回のスーパーSALEの行をコピーして `sale_id`・日付・URLを直すのが一番早いです

## 書き方のルール（共通）

- **セル内改行がそのまま改行になります**（`Option + Enter`）。タイトルの折り返しに使う
- `hero_sub`・`詳細`・`本文` の3つだけ `<strong>太字</strong>` が使えます
- `schedule` の `バッジ` … `main:本SALE | 50day:⏰ 5のつく日` のように `種類:表示名` を `|` 区切り
  - 種類は `announce` `pre` `main` `50day` `last` のいずれか（色が変わります）
- `schedule` の `誘導先` … `公式ページ :: https://…` を1行1件
- `schedule` の `タグ` … フィルタ用。`announce` `main` `50day` `last` をスペース区切り
- 日時は `2026-09-01 10:00` でも `2026/9/1 10:00` でもOK。時刻を省くと開始00:00・終了23:59

---

## やってはいけないこと

- **`ranking` シートを手で編集しない** — `buildRanking` が毎月1日に上書きします
- **`sale_id = common` の行を消さない** — サイト全体が表示できなくなります
- **列の順番を入れ替えない・列名を変えない** — スクリプトが列名で探しています
- **終わったセールの行を消す必要はありません** — 期間が過ぎれば自動で出なくなります
